# Citas-vet

## Overview

Citas-vet is a web application designed to manage veterinary appointments efficiently. It allows users to schedule, view, and manage appointments for their pets.

## Features

- Schedule new appointments
- View upcoming appointments
- Edit or cancel existing appointments
- User-friendly interface

## Technologies Used

- React
- Tailwind CSS
- Vite
